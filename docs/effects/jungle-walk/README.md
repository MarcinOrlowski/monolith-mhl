# Jungle Walk

An endless, constant-speed walk forward through dense, cartoon-styled Amazon
jungle undergrowth. The camera dollies straight ahead — no head bob or sway —
while foliage sheets loom out of the central vanishing point, sweep past the
edges and recycle, so the motion never visibly resets. Every leaf position and
shade is randomized, so the walk never repeats.

## Features

- Forward-only flythrough at a fixed, adjustable pace (no walking simulation /
  rocking).
- Layered "looming" foliage that fakes depth for a real sense of pushing through
  the jungle.
- Custom leaf, canopy/fog and light colors (greenish by default).
- Adjustable foliage density.
- Scene toggles: depth fog, light rays fanning from the vanishing point,
  floating spores drifting past the camera, and an edge vignette.
- Animation speed controls and FPS capping.
- Dimming control.
- Works with all post-processing filters.

## Settings

### Appearance

- **Foliage density** — how lush/leafy each foliage sheet is.
- **Leaf color** — the main foliage tone; lighter/darker shades are derived from
  it automatically.
- **Canopy / fog color** — the deep background the far foliage hazes into.
- **Light color** — the glow punching through at the vanishing point and the
  color of the light rays.

### Scene

- **Depth fog** — hazes distant foliage into the canopy light for added depth.
- **Light rays** — sun beams fanning out from the vanishing point.
- **Floating spores** — motes streaming past the camera.
- **Vignette** — darkens the frame edges.

### Animation

- **Walking speed** — forward dolly pace.
- **FPS cap** — limits the frame rate to save power.
- **Dim** — caps overall brightness.
