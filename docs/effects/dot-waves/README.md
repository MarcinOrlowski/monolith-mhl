# Dot Waves

## Features

- Animated grid of dots lit by a drifting sine/cosine brightness field.
- Adjustable dot spacing, size, density, edge softness and brightness.
- Custom dot and background colors.
- Optional independent "Shine" highlight layer that brightens already-visible
  dots. Choose between a wave-field or moving-spotlight spatial form, pick the
  modulation channel (color push, alpha boost or both), and tune intensity,
  width (how narrow the active band is), speed and color independently of the
  base animation.
- Animation speed controls and FPS capping.
- Dimming control.
- Works with all post-processing filters.
